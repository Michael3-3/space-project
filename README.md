🚀 Space Project Documentation

📝 Overview
Space Project is a frontend-only website that lets users explore various celestial destinations through a visually rich and responsive interface. Built to gain hands-on experience with React and Tailwind CSS, the project uses React Router for navigation and is deployed using Vercel.
🧰 Tech Stack
- Frontend: React
- Routing: React Router DOM
- Styling: Tailwind CSS
- Build Tool: Parcel
- Configuration: PostCSS
- Deployment: Vercel
  
🎯 Features
- Interactive, multi-page layout
- Responsive UI using Tailwind’s mobile-first design
- Clean component-based structure
- Deployed using Vercel for production-ready hosting
  
👨‍💻 Your Role
- Developed the full frontend independently
- Created modular components for each section (Home, Crew, Destination, Tech)
- Implemented responsive layout with Tailwind CSS
- Configured Parcel and Tailwind integration
- Deployed live build on Vercel

🚧 Challenges Faced
- Device Compatibility Issues:
  UI did not scale well on all screen sizes initially.
  ✅ Solution: Used Tailwind's responsive utilities (sm, md, lg, xl) to make layout fully responsive.

- Parcel + Tailwind Setup Issues:
  Had trouble with PostCSS and Tailwind working together.
  ✅ Solution: Fixed by setting up proper postcss.config.js and tailwind.config.js.
✅ Outcomes & Learnings
- Built a modular React application from scratch
- Developed confidence in using Tailwind for real-world UI work
- Learned SPA routing with React Router DOM
- Gained deployment experience via Vercel
